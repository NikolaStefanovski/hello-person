# Hello Person

A small Android app: type a name, then it greets them ("Hello, <name>!") inside a
frame of chasing, flashing marquee lights. Tap anywhere to launch fireworks; the
back button returns to the name screen.

## Install on your phone
Every push to `main` builds the app with GitHub Actions and publishes the APK as a
Release. Open **Releases → latest → HelloPerson.apk** on your phone and allow your
browser to install apps when Android asks.

## Build locally
Open the folder in Android Studio and press Run.
